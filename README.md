* **Hexo**: 快速、简洁且高效的静态博客框架。[hexo](https://github.com/hexojs/hexo/)
* **Hexo Theme Stellar**: 由 [xaoxuu](https://github.com/xaoxuu/hexo-theme-stellar) 开发的强大主题，具有极高的定制性和现代化的排版设计。
